# 使用说明

## 1. 首次启动

| 字段 | 说明 |
| --- | --- |
| 服务器地址 | 你的 JavBoss 服务端地址，例如 `http://192.168.1.1:8655`（可省略 `http://`，端口默认 8655） |
| 访问密钥 | 服务端设置的访问密钥 |

登录成功后会话以 Cookie 保存，之后自动登录。

## 2. 手机 / 平板

### 底部导航
`媒体库` · `视频` · `人物` · `厂牌` · `系列`

- **媒体库**：海报墙（无限滚动）、搜索、排序、筛选（观看状态 / 作品类型 / 喜爱度 / 收藏夹 / 编号前缀 / 厂牌 / 系列 / 人物 / 标签）
- **视频**：按文件维度浏览
- **人物 / 厂牌 / 系列**：点任意卡片**直接进入筛选结果**（没有单独详情页）

### 详情页
- 手机：单列，封面 → 标题 → 编号/日期/时长 → 喜爱度星级 → 编辑/收藏夹 → 剧集 → 人物/厂牌/系列/标签
- 平板：左右双栏，左栏封面 + 编号 + 日期 + 星级，右栏标题 + 剧集 + chips + 标签
- 长按封面可保存到相册（`Pictures/JavBoss`）
- 星级点同一颗可取消评分

### 播放器
| 操作 | 效果 |
| --- | --- |
| 单击画面 | 显示/隐藏控制条 |
| 双击左右 | ±10 秒 |
| 长按画面 | 2 倍速播放 |
| 左侧上下滑 | 亮度 |
| 右侧上下滑 | 音量 |
| `−10s` / `+10s` | 快退 / 快进 |
| 倍速按钮 | 0.5x – 2x |
| 退出 | 自动保存播放进度 |

进入已看过的视频会提示「继续播放 / 从头播放」，10 秒后自动继续。

## 3. Android TV

### 遥控器按键
| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动焦点（侧栏焦点移动**不会**切页，按 OK 才切） |
| OK | 确认 / 播放暂停 |
| 返回 | 依次：关闭弹窗 → 回到侧栏 → 返回上一页 |
| 设置键 | 打开应用设置 |
| ← / → （播放中） | 快退 / 快进 10 秒，可连按累加 |
| ↓ （播放中） | 切换播放倍速 |
| ↑ （播放中） | 信息条 / 播放队列 |

### 电视设置
- **连接**：服务器地址、访问密钥
- **显示与外观**：界面模式（自动/手机/平板/电视）、封面样式（跟随网页/横版/竖版）、每行卡片数（自动/3/4/5/6）
- **播放**：默认排序、优先直连播放、默认倍速
- **安全**：密码锁（4–6 位数字，遥控器数字键盘输入，输满自动解锁；连续错 5 次锁 30 秒）、超时锁屏（无操作 5/10/15/30/60 分钟）
- **其他**：诊断日志（二维码 → 手机扫码看全文）、退出登录

> 播放视频期间不会触发超时锁屏。

## 4. 常见交互
- **筛选结果不显示「继续观看」**：属于设计，只有默认列表才显示
- **焦点记忆**：从详情返回列表会回到刚才那一项；从播放器返回详情会回到刚才那一集
- **封面样式跟随网页**：服务端开启竖版海报时，客户端自动竖版；也可在本机设置里覆盖
