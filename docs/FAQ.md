# 常见问题

## 一、连不上服务端

### Q1. 同一台电脑浏览器能打开，手机/电视却连不上
最常见原因是**服务端所在电脑的防火墙没放通端口**。

**Windows 服务端放通步骤**
1. `Win + R` → 输入 `wf.msc` → 回车（打开「高级安全 Windows Defender 防火墙」）
2. 左侧点 **入站规则** → 右侧 **新建规则**
3. 类型选 **端口** → 下一步
4. 选 **TCP**，特定本地端口填 **8655**（你改过端口就填新端口）→ 下一步
5. 选 **允许连接** → 下一步
6. 三个配置文件（域 / 专用 / 公用）**全部勾选** → 下一步
7. 名称填 `JavBoss` → 完成

> 首次启动服务端时 Windows 会弹「是否允许访问网络」，如果当时点了**取消**，就会变成上面这种情况，需要手动加这条规则。

### Q2. 网络位置是「公用网络」
Windows 在「公用网络」下默认拒绝入站。把当前网络改成 **专用网络**：
`设置 → 网络和 Internet → 属性 → 网络配置文件 → 专用`。

### Q3. 服务端没开启局域网访问
服务端「设置 → 网络与代理」里需要**开启局域网访问**（默认只监听本机）。
Docker 部署默认已支持局域网访问。

### Q4. Docker 端口只绑定了 127.0.0.1
若 `docker-compose.yaml` 写成 `-p 127.0.0.1:8655:8655`，则只有宿主机能访问。
改成 `-p 8655:8655`，或用 `network_mode: host`。

### Q5. 手机/电视和服务端不在同一网段
- 确认手机、电视连的是**同一个 Wi-Fi**（不是访客网络）
- 路由器开了 **AP 隔离 / 客户端隔离** 时，设备之间无法互访，需要关掉
- 电视走有线、手机走 Wi-Fi 时，确认两者在同一子网（对比 IP 前三段是否相同）

### Q6. 服务端 IP 变了
路由器 DHCP 会给电脑重新分配 IP，建议在路由器里给服务端做 **静态 IP 绑定**，否则客户端地址要跟着改。

### Q7. 改了端口
App 里填的地址要带新端口，例如 `http://192.168.1.1:9000`。

### Q8. 用的是域名 / 反向代理
反向代理需要把 Cookie 与静态资源路径一并转发；若登录后图片仍是空白，多半是 Cookie 没透传。

## 二、登录与凭据

| 现象 | 原因 / 处理 |
| --- | --- |
| 提示访问密钥错误 | 服务端改过访问密钥，用新的重新登录 |
| 昨天还能用，今天 401 | 服务端重启导致会话失效，重新登录即可 |
| 列表正常但海报/图片全空 | 图片请求依赖登录 Cookie，说明当前会话已失效或未登录 |

## 三、播放相关

| 现象 | 处理 |
| --- | --- |
| 一直转圈 / 黑屏 | 在设置里切换「优先直连播放」（直连 ↔ HLS），或等服务端转码就绪后重试 |
| 播放卡顿 | 局域网带宽不足或码率过高；优先直连通常更流畅 |
| 有画面没声音 / 无字幕 | 部分内嵌字幕轨或特殊音轨不支持，可换源重试 |
| 进度不同步 / 继续播放位置不对 | 进度依赖服务端播放会话与本机记录，确认服务端未被清理 |

## 四、内容显示

| 现象 | 处理 |
| --- | --- |
| 海报空白 | 服务端尚未生成海报，回到服务端重新刮削 |
| 数量比实际少 | 服务端扫描/刮削未完成，等后台任务跑完或手动触发一次 |
| 海报竖版/横版与网页不一致 | 客户端默认「跟随网页」，可在本机设置里覆盖 |
| 每行卡片数不合适 | 设置里可调（自动 / 固定列数） |

## 五、安装与系统

| 现象 | 处理 |
| --- | --- |
| 电视提示「应用未安装」 | 电视架构需为 `arm64-v8a` 或 `armeabi-v7a`；x86 模拟器请用调试包 |
| 电视提示「禁止安装未知来源」 | 在电视「开发者选项」或「安全」里允许安装未知来源应用 |
| 安卓模拟器打不开 | 模拟器通常是 x86_64，需使用带 x86_64 的调试包 |
| 系统版本过低 | 最低 Android 5.1（API 22） |

## 六、隐私与安全

| 现象 | 处理 |
| --- | --- |
| 忘记本机密码 | 卸载重装会清空本机设置（不影响服务端数据） |
| 手机截屏是黑的 | 说明开着「隐私模式」，可在设置里关闭后再截图 |
| 想在电视上限制使用 | 设置里开启密码锁，并可配置无操作超时自动锁屏 |

## 七、提交问题前请先自查

1. 浏览器能否打开 `http://服务端IP:8655`？
2. App 里填的地址、端口、密钥是否与服务端一致？
3. 手机/电视与服务端是否同一网段？
4. 服务端是否开启了局域网访问、防火墙是否放通端口？
5. 换一台设备试试（排除单机问题）？

以上都确认后仍无法解决，再到 [Issues](../../issues/new/choose) 提交，并附上设备型号、系统版本、App 版本与复现步骤。
