# 常见问题（精简版）

本文只给**结论与最短操作路径**，完整步骤见 [客户端使用手册](USER-GUIDE.md) 的对应章节。

---

## 连接不上

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 连不上，提示失败 | 依次查：服务端在运行 → 已开启局域网访问 → 防火墙放行端口 → 同一 Wi-Fi | [§4](USER-GUIDE.md#4-首次连接) |
| 地址应该怎么填 | 按服务端所在系统/位置对照填写（Windows / Linux / macOS / NAS / 公网） | [§2](USER-GUIDE.md#2-服务器地址的填写方式) |
| Windows 防火墙怎么放行 | `Win + R` → `wf.msc` → 入站规则 → 新建规则 → 端口 TCP 8655 → 允许 | [§4](USER-GUIDE.md#4-首次连接) |
| Linux / macOS 放行端口 | Linux：`sudo ufw allow 8655/tcp`；macOS：系统设置 → 网络 → 防火墙 → 允许 JavBoss | [§4](USER-GUIDE.md#4-首次连接) |
| 填了 localhost 连不上 | 客户端要填服务端的局域网 IP，`localhost` 指的是设备自己 | [§2](USER-GUIDE.md#2-服务器地址的填写方式) |
| 昨天能用今天不行 | 服务端 IP 变了，重新查 IP；建议在路由器做静态绑定 | [§2](USER-GUIDE.md#2-服务器地址的填写方式) |
| 外网能否访问 | 可以，但需服务端侧做端口转发 / 内网穿透，客户端填公网地址 | [§2](USER-GUIDE.md#2-服务器地址的填写方式) |

## 登录

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 提示访问密钥错误 | 访问密钥 = 服务端登录密码，改过需同步 | [§4](USER-GUIDE.md#4-首次连接) |
| 不确定地址对不对 | 登录页点「测试连接」，会直接返回该地址是否可达 | [§4](USER-GUIDE.md#4-首次连接) |
| 之前能用，突然要求重新登录 | 服务端重启导致会话失效，重新输入即可 | [§4](USER-GUIDE.md#4-首次连接) |
| 封面全空白但列表正常 | 图片请求需登录凭据，说明会话已失效 | [§2](USER-GUIDE.md#2-服务器地址的填写方式) |

## 显示与数据

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 海报空白 | 服务端尚未生成海报，去服务端重新刮削 | [§14](USER-GUIDE.md#14-常见问题) |

## 播放

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 黑屏 / 一直转圈 | 设置里切换「优先直连播放」，或在播放页换源 | [§8](USER-GUIDE.md#8-播放器) |
| 播放卡顿 | 优先直连；电视建议有线网络 | [§8](USER-GUIDE.md#8-播放器) |

| 手机手势怎么用 | 单击显控制条、双击左右快进退、长按 2 倍速、左右滑动调亮度音量 | [§8](USER-GUIDE.md#8-播放器) |

## 字幕

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 加载很慢或失败 | 设置 → 字幕，配网络代理或字幕源反向代理 | [§9](USER-GUIDE.md#9-字幕) |
| 搜不到字幕 | 核对编号；关闭「仅中文字幕」后重试；或用本地文件/直链 | [§9](USER-GUIDE.md#9-字幕) |
| 字幕乱码 | 会自动识别常见编码；仍乱码说明文件异常，换一条 | [§9](USER-GUIDE.md#9-字幕) |
| 字幕不同步 | 用 ±0.1s / ±0.5s / ±1s 偏移，按编号记忆 | [§9](USER-GUIDE.md#9-字幕) |
| 有字幕却不显示 | 可能是硬字幕片源，可标记「本片无需字幕」 | [§9](USER-GUIDE.md#9-字幕) |
| 支持哪些格式 | SRT / ASS / SSA / VTT（`.sub` 按 SRT 解析）；不支持 VobSub、PGS 等图形字幕 | [§9](USER-GUIDE.md#9-字幕) |
| 番号搜不到 | 新版会自动归一化大小写 / 全角 / 空格；若仍搜不到，确认该作品已入库 | [§5.1](USER-GUIDE.md#51-搜索技巧) |
| 列表内容突然变了一批随机片 | 点过「随机」，点顶部提示条「点此返回」即可恢复 | [§5.2](USER-GUIDE.md#52-随便看看) |
| 海报上的「中 / 虚线空圈」是什么 | 分别表示已配字幕 / 已标记无需字幕 | [§9.6](USER-GUIDE.md#96-字幕状态与角标) |
| 怎么快速找出没字幕的片 | 列表页打开筛选面板 → 分类「字幕状态」→ 选「无字幕 / 已匹配」 | [§9.7](USER-GUIDE.md#97-按字幕状态筛选) |
| 批量补齐字幕会不会重复下载 | 已配 / 无字幕 / 无需字幕都会跳过；进度保存在本地，中断后重新进入可继续，已处理的编号不重复 | [§9.8](USER-GUIDE.md#98-批量补齐字幕) |
| 手机补完字幕，电视上没有 | 字幕状态存于本机；用「导出字幕索引」→「导入字幕索引」同步 | [§9.10](USER-GUIDE.md#910-导出与跨设备同步) |
| 影片自带字幕怎么用 | 播放器字幕面板中可直接切换内嵌字幕轨（不写入字幕状态索引） | [§9.3](USER-GUIDE.md#93-内嵌字幕与硬字幕) |

## 更新

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 下载很慢 / 镜像不可用 | 设置里切换下载镜像或测速；也可直连下载 | [§10](USER-GUIDE.md#10-应用内更新) |
| 点了安装没反应 | 手机确认允许未知应用；电视可 U 盘手动安装 | [§10](USER-GUIDE.md#10-应用内更新) |
| 安装包校验不通过 | 下载的包与 GitHub 记录的 SHA-256 不一致（可能被代理篡改或下载中断），安装包会被删除、安装中断；重试或到 Releases 手动下载 | [§10](USER-GUIDE.md#10-应用内更新) |
| 提示「发现新版本」但其实已是最新 | 已修复：现在只有 GitHub 版本高于当前版本时才提示；若仍出现，说明本机版本低于发布版本，可按提示更新 | [§10](USER-GUIDE.md#10-应用内更新) |
| 版本号没变化 | 装错了安装包；重下当前版本，应用内更新会校验版本 | [§10](USER-GUIDE.md#10-应用内更新) |
| 提示「拿不到安装包校验摘要，已中止安装」 | 设计如此：拿不到可信校验值时不会强行安装，请到 Releases 手动下载 | [§10](USER-GUIDE.md#10-应用内更新) |

| 电视提示「应用未安装」 | 需 `arm64-v8a` / `armeabi-v7a`，并允许未知来源安装 | [§3](USER-GUIDE.md#3-安装) |

## 隐私与安全

| 现象 | 处理 | 详见 |
| --- | --- | --- |
| 忘记本机密码 | 卸载重装清除客户端设置，服务端数据不受影响 | [§11](USER-GUIDE.md#11-隐私与安全) |
| 截屏是黑的 | 关闭「隐私模式」 | [§11](USER-GUIDE.md#11-隐私与安全) |
| 播放中会被超时锁屏吗 | 不会，播放期间不触发 | [§11](USER-GUIDE.md#11-隐私与安全) |
| 电视设了密码却从没弹过锁 | 旧版本只开开关没存密码；0.37.0 起会真正保存，请重新设置一次密码 | [§11](USER-GUIDE.md#11-隐私与安全) |
| 换手机了怎么带走设置 | 设置 → 备份与恢复 → 导出 / 分享备份，新机导入（分「仅恢复数据」「全部恢复」） | [§13](USER-GUIDE.md#13-管理功能) |
