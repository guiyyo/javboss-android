# 常见问题

### 登录提示连接失败
- 确认手机/电视与服务器在同一局域网，地址形如 `http://192.168.1.1:8655`
- 用手机浏览器打开该地址，能否看到服务端页面
- 服务端若开了防火墙，放行 8655 端口

### 封面全是空白
- 封面走鉴权 Cookie，确认已成功登录
- 服务端未生成封面时也会空白，可在服务端重新刮削

### 电视装不上 APK
- 电视必须是 `armeabi-v7a` 或 `arm64-v8a`（模拟器 x86 需调试包）
- 用 U 盘或 `adb install -r javboss-android-<ver>-arm64-armv7.apk`
- 部分电视需要在「开发者选项」打开「允许安装未知来源」

### TV 遥控器没有「设置」键 / 无效
- 部分电视系统会占用该键，此时用侧栏最后一项「设置」

### 播放黑屏或一直转圈
- 设置里切换「优先直连播放」开关（直连 / HLS 互切）
- 服务端转码未就绪时，稍等或重试

### 密码锁忘记
- 卸载重装会清空本机设置（不影响服务端数据）

### 时间/进度不对
- 「继续观看」依赖服务端播放会话 + 本机进度，两边都会同步
