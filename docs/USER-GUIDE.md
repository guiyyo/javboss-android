## 1. 客户端与服务端的关系

| 角色 | 说明 |
| --- | --- |
| **服务端（JavBoss）** | 运行在电脑或 NAS 上的程序，负责扫描媒体目录、生成海报、获取影片信息，并通过网络提供数据 |
| **客户端（本 App）** | 安装在手机、平板或电视上的程序，连接服务端后浏览与播放；本身不保存任何影片文件 |

两点说明：

- 客户端需要连接一个已运行的服务端，才能浏览内容。
- 客户端与网页端使用同一份数据。在客户端修改评分、收藏夹、标签等，网页端会同步显示相同结果。

## 2. 服务器地址的填写方式

客户端需要填写一项「服务器地址」，填写内容取决于服务端的部署位置：

| 服务端部署位置 | 填写内容 | 说明 |
| --- | --- | --- |
| Windows 电脑（一键安装或解压运行），与手机/电视连接同一 Wi-Fi | `http://电脑局域网IP:8655`<br>例：`http://192.168.1.1:8655` | 电脑关机或睡眠时客户端无法连接 |
| NAS（Docker 部署） | `http://NAS的IP:8655`<br>例：`http://192.168.1.1:8655` | 需在服务端开启局域网访问；NAS 通常长期开机 |
| 局域网内的其他电脑 | 该电脑的 IP 与端口 | 与物理位置无关，能互通网络即可 |
| **Linux 服务器**（直接运行或 Docker） | `http://服务器IP:8655`<br>例：`http://192.168.1.1:8655` | 需在防火墙放行端口（`ufw` 或 `firewalld`）；用 `hostname -I` 或 `ip addr` 查看 IP |
| **macOS**（直接运行） | `http://Mac局域网IP:8655`<br>例：`http://192.168.1.1:8655` | 首次运行时系统可能询问"是否允许接收入站连接"，需选择允许；用 `ipconfig getifaddr en0` 查看 IP |
| 需要在外网访问（移动网络、公司网络） | 公网域名或公网地址，例：`https://your-domain.com` | 需在服务端侧配置端口转发、内网穿透或反向代理；使用 HTTPS 时证书需有效 |
| 使用 JavBoss 的 Client 模式（电脑端反代远程服务端） | 远程服务端的地址 | Client 模式用于电脑端播放，客户端直接连接远程服务端即可 |

补充说明：

- 服务端端口若不是 8655，地址中需带上实际端口，例：`http://192.168.1.1:9000`。
- 地址建议带 `http://` 或 `https://`；未填写时客户端默认补 `http://`。
- Docker 部署需确认容器端口已映射到宿主机（如 `-p 8655:8655` 或 `network_mode: host`），否则客户端无法访问。
- 无论服务端运行在 Windows、Linux 还是 macOS，都需要在服务端设置中开启「局域网访问」，手机、平板、电视才能连接。

### 查看服务端 IP

| 服务端系统 | 查看方式 |
| --- | --- |
| Windows | `Win + R` → `cmd` → 输入 `ipconfig` → 查看「IPv4 地址」 |
| Linux | 终端执行 `hostname -I`，或 `ip addr show` 后查看 `inet` 字段（忽略 `127.0.0.1`） |
| macOS | 终端执行 `ipconfig getifaddr en0`（有线）；无线通常为 `en1`；也可在「系统设置 → 网络 → Wi-Fi → 详细信息」中查看 |

建议在路由器中为服务端设备设置固定的 DHCP 分配，避免 IP 变化后需要重新填写地址。

## 3. 安装

### 3.1 手机 / 平板

1. 在 Releases 页面下载最新 `javboss-android-<版本>-arm64-armv7.apk`。
2. 使用文件管理器打开该文件。
3. 系统提示「禁止安装未知来源应用」时，进入提示页开启对应来源的安装权限。
4. 完成安装。

### 3.2 电视 / 电视盒子

| 方式 | 步骤 |
| --- | --- |
| U 盘 | 将 apk 复制到 U 盘，插入电视后用系统自带的文件管理器打开安装 |
| 电视助手应用 | 使用当贝助手、沙发管家等工具推送安装 |
| 命令行 | 电脑执行 `adb install -r javboss-android-<版本>-arm64-armv7.apk` |

如提示未知来源限制，在电视的「设置 → 安全」中允许安装未知来源应用。

安装包支持 `arm64-v8a` 与 `armeabi-v7a` 架构，覆盖绝大多数电视与电视盒子。

## 4. 首次连接

首次打开客户端，在登录页填写两项内容：

| 填写项 | 内容 |
| --- | --- |
| 服务器地址 | 按[第 2 节](#2-服务器地址的填写方式)对照填写 |
| 访问密钥 | 服务端的登录密码 |

填写完成后点击「连接」。连接成功后会话会保存在本机，后续打开无需重复输入。

登录页还提供以下辅助项：

| 项 | 说明 |
| --- | --- |
| 端口提示 | 地址未写端口时会提示「JavBoss 默认 8655」，可点「补上 :8655」自动补全 |
| 测试连接 | 仅请求服务端健康检查接口，用于验证地址与网络是否可达，不改变登录状态 |
| 地址为空 | 会直接提示先填写服务器地址，不会回落到任何预设地址 |

### 连接失败时的排查顺序

| 顺序 | 检查项 | 确认方式 |
| --- | --- | --- |
| 1 | 服务端是否正在运行 | 在服务端所在电脑的浏览器打开 `http://localhost:8655`，能打开页面即表示服务端正常 |
| 2 | 客户端与服务端是否在同一局域网 | 连接同一 Wi-Fi；电视不要连接访客网络 |
| 3 | 服务端是否开启局域网访问 | 在服务端设置中开启「局域网访问」；部分版本需重启服务端生效 |
| 4 | 防火墙是否放行端口 | **Windows**：`Win + R` → `wf.msc` → 入站规则 → 新建规则 → 端口 → TCP → 填入端口号 → 允许连接 → 勾选全部网络类型 → 命名保存<br>**Linux**：`sudo ufw allow 8655/tcp`，或 `sudo firewall-cmd --add-port=8655/tcp --permanent && sudo firewall-cmd --reload`<br>**macOS**：系统设置 → 网络 → 防火墙 → 选项，允许 JavBoss 接收入站连接 |
| 5 | 路由器是否开启 AP 隔离 | AP 隔离会阻断同一 Wi-Fi 下设备间的访问，需在路由器中关闭 |
| 6 | IP 是否已变化 | 重新执行 `ipconfig` 核对；路由器重启后 IP 可能改变 |
| 7 | 是否为公网地址 | 确认端口转发或内网穿透配置正确；HTTPS 证书需有效 |

判断方法：用手机浏览器打开同一地址。浏览器可打开而客户端无法连接时，通常为密钥不正确或协议不匹配；两者都无法打开时，通常为网络或防火墙问题。

## 5. 手机端

底部导航包含 5 个入口：**JAV · 视频 · 演员 · 厂商 · 系列**。

| 位置 | 功能 |
| --- | --- |
| 顶部搜索框 | 按编号（如 `SNOS-079`）或标题关键词检索 |
| 筛选 | 组合筛选：类型、标签、人物、厂商、系列、编号前缀、观看状态、评分、收藏夹 |
| 排序 | 最近更新、时长、评分、观看次数；同一项再次点击切换升序与降序 |
| 海报墙 | 上下滑动浏览，滚动到底自动加载下一页 |
| 详情页 | 海报、编号、日期、时长、评分、收藏夹、标签、剧集列表 |
| 观看记录 | 从首页入口进入，可继续上次的播放位置 |

详情页可执行的操作：

- 点击星级评分，再次点击同一星级可取消评分。
- 加入或移出收藏夹。
- 长按海报可保存到相册。
- 点击标签、人物、厂商、系列，进入对应的筛选结果。
- 点击剧集开始播放。

| 项目 | 平板端表现 |
| --- | --- |
| 列表 | 一屏显示多列海报，默认 3 列，可在设置中调整 |

## 7. 电视端

电视端为遥控器操作单独设计的界面：左侧导航栏，配合焦点框选。

### 7.1 遥控器按键

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动焦点；在左侧导航栏移动只改变高亮，按 OK 才切换页面 |
| OK | 确认 / 播放暂停 |
| 返回 | 依次执行：关闭弹窗 → 返回左侧导航栏 → 返回上一页 |
| ← / → | 播放中快退 / 快进 10 秒，可连续按键累加，屏幕显示目标时间 |
| ↑ | 播放中显示信息条与播放队列 |
| ↓ | 播放中切换倍速（0.75x / 1x / 1.25x / 1.5x / 2x） |
| 字幕键、菜单键 | 播放中打开字幕面板 |
| 设置键 | 打开客户端设置；部分电视系统会占用该键，此时使用左侧导航栏底部的「设置」 |

### 7.2 交互特点

| 设计 | 说明 |
| --- | --- |
| 焦点记忆 | 从详情页返回列表时，焦点回到此前选择的条目 |
| 导航不误触 | 左侧导航栏移动焦点不切换页面，按 OK 才切换 |
| 分层返回 | 依次关闭弹窗、返回导航栏、返回上一页，不会一次退出应用 |

### 7.3 设备识别

客户端会识别设备类型：电视自动使用电视界面，手机与平板使用触屏界面。也可在设置中将界面模式固定为手机、平板或电视。

## 8. 播放器

### 8.1 播放源

| 播放源 | 说明 |
| --- | --- |
| 直连（Direct） | 直接播放原始文件，画质无损失，对带宽要求较高 |
| HLS | 分段流播放，网络状况不佳时更稳定 |

可在设置中选择「优先直连播放」；播放失败时也可手动切换到另一播放源。

### 8.2 播放进度

- 自动记录每部影片的播放位置。
- 再次打开已看过的影片时，会提示「继续播放 / 从头播放」，10 秒内无操作将自动继续播放。
- 电视端使用方向键切换选项，按 OK 确认。

### 8.3 操作方式

| 端 | 操作 |
| --- | --- |
| 手机 / 平板 | 单击画面显示控制条；双击左/右区域快退/快进 10 秒；长按画面以 2 倍速播放；左右滑动调整亮度与音量；支持画中画 |
| 电视 | 见 [7.1 遥控器按键](#71-遥控器按键) |

### 8.4 其他

- 播放倍速 0.5x – 2x。
- 多集内容可在信息条中切换播放队列。
- 退出播放时自动保存进度。

## 9. 字幕

字幕功能为客户端内置，支持外挂字幕的搜索、加载与校正。

### 9.1 字幕来源

| 来源 | 使用方式 |
| --- | --- |
| 在线搜索 | 打开字幕面板后按编号搜索，选择一条加载；可更换源、可重试 |
| 已下载 | 从之前下载过的字幕中选择 |
| 本地文件夹 | 选择设备上的字幕文件夹，按编号自动匹配 |
| 直链 | 粘贴字幕文件地址 |

支持的格式：**SRT / ASS / SSA / VTT / SUB**，加载时统一转换为 SRT 渲染。
自动识别的编码：**UTF-8 / UTF-16 / GBK / GB18030 / BIG5**。

### 9.2 时间偏移

字幕与画面不同步时，可使用 **±0.1s / ±0.5s / ±1s** 进行调整，调整后立即生效，不会重新加载视频。

### 9.3 内嵌字幕与硬字幕

- 影片自带字幕轨时，客户端会检测并可直接切换使用。
- 硬字幕片源（字幕已烧录在画面中）可标记为「本片无需字幕」，之后不再自动加载外挂字幕。

### 9.4 记忆

客户端按编号记录所选字幕与偏移值，下次播放同一影片时自动套用。

### 9.5 字幕加载较慢时的处理

字幕源站在部分网络环境下响应较慢（单次可能 16–45 秒）。可在「设置 → 字幕」中配置以下任一加速方式：

| 方式 | 填写内容 |
| --- | --- |
| 网络代理 | 已有代理的地址与端口（HTTP 或 SOCKS5），仅作用于字幕、更新等外网请求，不影响访问服务端 |
| 字幕源反向代理 | 自建反向代理的主机、端口与协议，配置后通常 1 秒内返回结果 |

另有以下选项可减少等待：

- 中文字幕优先：搜索结果按简体中文、繁体中文、其他语言排序。
- 仅中文字幕（默认开启）：过滤非中文条目。

### 9.6 字幕状态与角标

客户端会为每部影片记录字幕状态，并保存在本机（不同设备各自独立）：

| 状态 | 含义 | 列表角标 |
| --- | --- | --- |
| 已配字幕 | 已加载或下载了外挂字幕 | 「中」 |
| 内嵌字幕 | 影片自带字幕轨并经播放实测确认 | 「中·嵌」 |
| 无字幕 | 字幕站确实没有该编号 | 不显示 |
| 无需字幕 | 手动标记为硬字幕或不需要 | 虚线空圈 |

角标显示在海报右上角（与「无码」等标记同列）；「继续观看」等小卡片使用紧凑样式，显示在左上角。

### 9.7 按字幕状态筛选

在列表页打开**筛选面板**，选择「**字幕状态**」分类，可选：**全部 / 已匹配 / 无字幕 / 无需字幕**。
用于快速找出还没配字幕的影片。电视端同样在筛选面板中（分类名为「字幕」）。

### 9.8 批量补齐字幕

入口：设置 → 字幕 → **批量补齐字幕**（电视端在设置 → 字幕分组内）。

| 项 | 说明 |
| --- | --- |
| 处理范围 | 全部 / 前 20 / 前 100，建议先小范围试跑 |
| 请求间隔 | 1.5 / 2 / 3 秒，用于降低字幕站风控概率 |
| 跳过规则 | 已配字幕、已标记无需字幕、已判定无字幕的作品会跳过 |
| 匹配规则 | 候标题归一化后必须与编号完全一致才下载（`JUR-897` 不会匹配 `JUR-8970`） |
| 优先级 | 命中偏好语言、编号匹配优先；标题含 HD/4K 等会降权；人工翻译优先于机翻 |
| 后台运行 | 退到后台或锁屏仍继续，通知栏显示进度 |
| 中断恢复 | 进程被杀后重新打开会自动续跑，已处理的编号不重复 |

无匹配或下载失败的条目会进入**待人工处理**列表，可逐条「查看候选 / 重试 / 无需字幕 / 忽略」，也可批量「全部重试 / 全部标记无字幕 / 清空列表」。

### 9.9 字幕语言偏好

设置 → 字幕 → **字幕语言偏好**：可增删语言并调整顺序（↑↓）。靠前的语言优先用于「已配」判定与补齐打分；未知语言不会被排除，避免漏补。

### 9.10 导出与跨设备同步

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 导出已匹配字幕 | 设置 → 字幕 → 导出已匹配字幕 | 打包为 ZIP，条目名为 `番号.语言.srt`，便于备份或在其他设备导入 |
| 导出字幕索引 | 设置 → 字幕 → 导出字幕索引 | 导出本机字幕状态为 JSON |
| 导入字幕索引 | 设置 → 字幕 → 导入字幕索引 | 按更新时间合并（同编号取较新），用于多设备共享结果 |

电视端将文件写入 `Android/data/<包名>/files/subtitles/`，可在同一目录取放 `index-export.json` 与 `javboss-subtitles.zip`。

> 字幕状态保存在各设备本地，因此手机扫过的结果不会自动出现在电视上，需要用导出 / 导入同步。

### 9.11 播放器中的纠正方式

- **标记有内嵌字幕**：自动识别未命中时，可在播放器字幕面板手动标记，写入本机索引。
- **本片无需字幕**：硬字幕片源标记后，不再自动加载外挂字幕。

## 10. 应用内更新

| 功能 | 说明 |
| --- | --- |
| 检查更新 | 可在设置中手动检查；启动后也会自动检查一次，不阻塞界面 |
| 下载并安装 | 应用内下载并显示进度，完成后调用系统安装器 |
| 下载镜像 | 内置多个加速镜像，可测速后选用最快的一项；也可填写自定义镜像 |
| 版本校验 | 下载前后均校验安装包版本，版本不符时提示「期望 vX，实际 vY」并停止安装 |
| 完整性校验 | 下载完成后校验安装包 SHA256，不匹配则拒绝安装 |

电视端说明：

- 首次安装更新时，系统可能要求确认安装未知来源应用，确认一次即可。
- 若系统始终不弹出安装界面，可在电脑下载安装包后通过 U 盘安装。

## 11. 隐私与安全

| 功能 | 适用端 | 说明 |
| --- | --- | --- |
| 指纹锁 | 手机 / 平板 | 冷启动与设备锁屏后需指纹或系统密码解锁 |
| 隐私模式 | 手机 / 平板 | 开启后禁止系统截屏与任务预览；可关闭 |
| 密码锁 | 电视 | 4–6 位数字密码，使用遥控器输入，位数输满自动校验；连续错误 5 次后锁定 30 秒 |
| 超时锁屏 | 电视 | 无操作达到设定时间后回到密码页；播放视频期间不触发 |
| 本地数据 | 全部 | 设置、播放进度、字幕索引保存在本机，不上传第三方 |

本机密码遗忘时，可通过卸载重装清除客户端设置，服务端数据不受影响。

## 12. 设置项说明

| 设置项 | 作用 |
| --- | --- |
| 界面模式 | 自动 / 手机 / 平板 / 电视；「自动」按设备类型判断 |
| 封面样式 | 跟随网页 / 横版 / 竖版；选择「跟随网页」时与服务端设置保持一致 |
| 每行卡片数 | 自动或指定列数 |
| 默认排序 | 列表打开时使用的排序方式 |
| 默认倍速 | 播放器的起始倍速 |
| 优先直连播放 | 在直连与 HLS 之间选择优先使用的播放源 |
| 网络代理 | HTTP / SOCKS5 的主机与端口，仅作用于字幕、更新等外网请求 |
| 字幕源反向代理 | 主机、端口与协议，用于加速字幕请求 |
| 仅中文字幕 | 开启后只保留中文字幕条目 |
| 字幕语言偏好 | 语言优先级排序，影响已配判定与补齐打分 |
| 批量补齐字幕 | 对缺失字幕的作品自动搜索并下载 |
| 导出 / 导入字幕索引 | 在多台设备间同步字幕状态 |

## 14. 常见问题

按问题类型整理的速查表见 [常见问题（精简版）](FAQ.md)。以下为与本手册流程直接相关的几点：

| 情况 | 说明 |
| --- | --- |
| 连接失败 | 按[第 4 节](#4-首次连接)的排查顺序逐项确认，最常见原因是未开启局域网访问或防火墙未放行端口 |
| 服务端 IP 变化 | 重新查看 IP；建议在路由器设置固定 DHCP 分配 |
| 海报空白 | 服务端尚未生成海报，需在服务端重新刮削 |
| 字体/布局与预期不同 | 检查「界面模式」与「每行卡片数」设置；平板与电视的字号由屏幕宽度决定 |
| 需要提交问题 | 见 [FAQ 的反馈说明](FAQ.md#仍未解决) |

## 15. 术语

| 术语 | 说明 |
| --- | --- |
| 服务端 | 运行中的 JavBoss 程序，负责扫描、获取信息并提供数据 |
| 客户端 | 本 App，安装在手机、平板或电视上 |
| 访问密钥 | 连接服务端使用的密码，即服务端登录密码 |
| 端口 | 服务端监听的端口号，JavBoss 默认为 8655 |
| IP 地址 | 设备在局域网中的地址，格式如 `192.168.1.1` |
| NAS | 网络存储设备，通常长期运行 |
| Docker | 一种程序打包与运行方式，常见于 NAS 部署 |
| 直连 | 直接播放原始文件，画质无损失，对带宽要求较高 |
| HLS | 分段视频流，网络波动时更稳定 |
| 刮削 | 依据编号从网络获取标题、海报等信息的过程 |
| 编号 | 影片编号，如 `SNOS-079`，用于搜索与信息获取 |
| 内嵌字幕 | 封装在视频文件中的字幕轨，可切换开关 |
| 硬字幕 | 已烧录进画面的字幕，无法关闭或替换 |
| 偏移 | 字幕与画面之间的时间校正量 |
| 反向代理 | 位于中间的转发服务，用于加速或转发请求 |
| SAF | Android 的文件选择授权机制，用于读取用户指定的文件夹 |
